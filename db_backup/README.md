# データベースバックアップ

このフォルダにはアプリのデータベースバックアップ (`.sql.gz`) を保存します。

## フォルダ構成

```
db_backup/
├── translations/    翻訳データ (translations テーブル)
├── glossary/        用語集 (glossary テーブル)
├── index/           ゲームデータインデックス (ships, items, missions 等)
└── all.sql.gz       全データの一括バックアップ
```

## エクスポート方法

### GUI
設定タブ → データベース → **エクスポート (バックアップ)** ボタン

### コマンドライン
```powershell
.\export_backup.ps1
```

## インポート方法

設定タブ → データベース → **インポート (復元)** ボタン

インポート時にダイアログで取り込むデータを選択できます:
- 翻訳データ
- 用語集
- ゲームデータインデックス

## チームでの共有

1. エクスポートしたファイルをこのフォルダに保存
2. git commit & push
3. チームメイトが pull してアプリの **インポート** で取り込み
