# 作業内容: 銃のアタッチメントとダメージ判定、日本語化の改善（2026-10-13）

v2.0.0 として公開済み（コミット 22fa9d4）。

## 目的
- 個人武器にどのスコープ・マズル・アンダーバレル・マガジンが付くかを、ゲームデータから判定する。
- 付けたときのダメージを比べられる画面を作る。
- 途中で見つかった日本語化・表示・検索の不具合を直す。

## 利用者が決めた仕様
- ［個人戦闘］をサブタブに分ける。［表］は今のまま、［ダメージ判定］を新設。元の表にはオプションを入れない（表が大きくなりすぎるため）。
- ダメージ判定は［銃の分類］［銃の名前］［スコープ］［マズル］［アンダーバレル］［マガジン］を選び、今の表と同じ項目を「オプションなし（既定）」と「選択したオプション」の2行で出す。
- 色違いは一つにまとめ、「（色違い: …）」と書き添えるだけにする。
- 偽物（behr_binoculars_01_FakeOptic*、volt_ubarrel_flsh_s1_Sniperglint、vlk_spewgun_ のマガジン）は名前で除外する。
- 補正は `*Multiplier` を掛け算として扱い、画面に「推定」と注記する。
  - 対象は damage / fireRate / projectileSpeed / chargeTime。
  - 連射倍率は、連続動作の delay と、バースト・チャージの cooldownTime にも掛ける。chargeTime には掛けない。
- マガジンに「なし」は置かない。枠が無い銃の欄は灰色で空にする。
- 詳細とチャットには、付けられるアタッチメントの一覧を表で出す（パーツ / サイズ / アタッチメント / 色違い）。枠が無い武器には章を出さない。
- 品名は「日本語名 (英語名)」で出す（詳細・色違い・［表］・ダメージ判定・船舶戦闘）。並べ替えと色違いの一覧は英語名の順。
- 射撃モード名を日本語にする: ビーム、連射ビーム、連続、散弾、自己回復、採掘ビーム、サルベージ、トラクタービーム、消火。
- 公式の日本語 ini の「! JAPANESE_(JAPAN) TRANSLATION NOT FOUND」は、訳が無いものとして AI 翻訳に回す。公式訳が印に変わったら、古い公式訳を捨てる。
- 検索用の name_ja は、item_index.name_key でキーを照合する。キーで見つからないものだけ英語名の完全一致で補う。

## 変更したファイル
- `GameDataExtractor.cs`
  - 個人武器・付属品を slim 化するときも、SItemPortContainer と SWeaponModifier を残す。
  - 個人用マズル（FPS_Barrel）を店の価格を取る対象に入れる。
  - item_index.name_key を追加し、name_ja をキーで照合する。
  - 移行のときに item_vectors を一度だけ消す。
  - 埋め込みのモデルを専用のもの（gemini-embedding-001 など）にし、エラーの本文をログに出す。
- `GameDataQueryService.Attachments.cs`（新規）: 装着の判定、補正の取り出し、一覧の文、補正を入れた1行の計算。
- `WeaponDamageCheckPanel.xaml(.cs)`（新規）: ダメージ判定の画面。
- `MainWindow.xaml`: ［個人戦闘］のサブタブ。
- `GameDataQueryService.cs` / `.Detail.cs` / `.WeaponTable.cs`: 日本語名、射撃モード名、アタッチメントの章、cstone の英文の除去、色違いの並び。
- `DetailPanel.xaml.cs`
  - WebView2 の初期化を一度だけにする。失敗をログに残す。
  - 「読み込み中...」が残る・早く消える不具合を直す。
  - 空の一覧を隠す。
- `ChatService.cs`: 銃の一覧を AI に渡す、埋め込みのモデル、cstone の英文。
- `TranslationDatabase.cs` / `TranslationOrchestrator.cs` / `IniMerger.cs`: 「訳が無い」印の扱いと定数。
- `WeaponTablePanel.xaml.cs`: 一部を internal に。
