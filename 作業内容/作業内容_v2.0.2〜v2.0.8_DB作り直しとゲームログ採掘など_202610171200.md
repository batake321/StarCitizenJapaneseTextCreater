# 作業内容: v2.0.2〜v2.0.5（2026-10-14〜17）

## v2.0.2 インストール後に DB が空になる不具合
- 原因: 起動時の同梱 DB の取り込みが日時比較だけ／FTS の影の表への INSERT で COMMIT が全部取り消し／v1.x の列不足／構築途中失敗で空のまま／同梱 DB の作者 PC の日時で誤った「パッチ更新あり」。
- 利用者の決まり: a = 作業フォルダの DB、b = 同梱 DB またはインポートする DB。「ユーザーが入力したものは残す、他は b で上書き」。
  - 残す: 手動・CSV・用語集の訳、用語集、チャットの記憶、My Hangar 同期データ、所持船・所持コンポーネント・装備の割り当て。この PC だけの印（価格取得中・中止）は a だけ。
  - 上書き: ゲーム・ネットの公開データ全部。
- 同梱 DB は .tmp に作って入れ替え、古い DB は .bak 1 世代。失敗は app_log と MessageBox。インポートも同じ決まりで、「追加・上書き・全置換」の選択は無くした。
- 構築前の控えと失敗時の戻し。gamedata_meta は構築が作り直すキーだけ消す。wiki のミッション情報を引き継ぐ。パッチ更新の判定は build_manifest.id の版で。
- 自動モードの安全チェックが release.ps1 と設定の書き換えを止めた → 利用者が自動モードを抜けて実行。.claude/settings.local.json に release.ps1 と git push の許可を足した。
