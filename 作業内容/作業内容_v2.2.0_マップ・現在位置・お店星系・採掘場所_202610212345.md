## 作りの要点
### 採掘できる場所（ore_locations）
- 構築の Step 6c で、HarvestableProviderPreset の SpaceShip/GroundVehicle/FPS_Mineables のグループから作る。出やすさ = relativeProbability ÷ グループ内の合計。岩の中の割合は MineableComposition。
- 詳細タブの資源の詳細に表（出やすさ×割合の列あり）。分類「鉱石」。鉱石タブの資源・BP の材料のダブルクリックで開く（BP は材料を全部リストへ）。
- 参照はファイル名だけで引くと同じ名前の別ファイルに取り違えるので、records の下のパスで引く（deliverable_sources も同じく直した）。

### お店・ステーション・星系（ゲームデータ＋DB の価格）
- starmap_locations（StarMapObject、座標・自転の列つき）、game_shops（socpak の SCShop と場所）、shop_price_links（item_shop_prices・trade_prices との紐づけ。店まで／場所までの 2 段）、starmap_entities（socpak の Child の名前 → 星図。量子ジャンプの目的地の名前を引く）。
- 表の形の番号 ShopTablesFormat（今は "4"）と gamedata_meta の shop_tables_attempt_build で、起動後の補完を同じ版・同じ形では 1 回だけにする。表や列を足したら番号を上げる。
- 詳細タブ: Shop:/PriceShop:/Place:/System: の record、リンク [[record|名前]] → scjt://detail/…、［戻る］10 件、星系図・近くの図・【距離】。

### 座標と自転（実測で確かめた）
- 座標は恒星を原点にしたメートル。絶対座標 = R(q_恒星)·(P_惑星 + Rz(θ)·(R(q_惑星)·p_local))。Pyro の恒星だけ rot=0.73592025,0,0,-0.67706823。
- 自転の時間は socpak の xml の planetRotationSpeed（時間）。θ = 360×UNIX 秒÷(rot_hours×3600) ＋ 惑星ごとの補正値。**起点は惑星ごとにばらばら**（Bloom −0.23°、Pyro I +163°）。速さはデータどおり（Bloom で 0.2% 以内）。
- 補正は［現在位置］で取った座標から: Game.log の着陸場所を優先、無ければ中心からの距離と z が 5 Km 以内の子（地表の子は候補が 1 つに決まるときだけ）。
- 契約の目標の印（CObjectiveMarkerComponent の ZonePos）は惑星の中心からの位置（|ZonePos| が半径と一致）。

### マップタブ・［現在位置］
- /showlocation はチャットに打つとクリップボードに「Coordinates: x:… y:… z:…」が入る（Game.log には出ない）。SendInput のスキャンコードで送る（キー 10ms）。
- 送る前にゲームの窓の下 12% を撮って Windows OCR で mobiGlas の帯（ホーム・マップ…のタブ）を見て、開いていれば送らない。
- クリップボードは全形式を覚えて戻す（覚えられなければ送らない）。設定の保存は一時ファイルから入れ替え。
- 推定位置の段: 取った座標（今の Game.log の中で、死亡・復活より後、取った後に Location が変わっていない）→ 着陸場所 → 覚えた Location の番号 → QT 到着地点付近。
- 量子ジャンプ: 目的地の選択で「設定」、Location の変化で「移動中」、宇宙から別の番号に変わって 15 秒そのままなら「途中で停止」（到着の行は最終の目的地のときだけ出る）、「Quantum Drive Arrived」で到着。線は破線＋真ん中の矢印、はみ出したら 8 割に収める。地図は作り直さず PostWebMessageAsJson で書き換える。
- 「QT の前後で自動で現在位置を取る」（既定オフ）: 選択ですぐ（取れなければ 3 秒おきにあと 2 回）、到着の 2 秒後。

### ゲームログ
- ハンガー進入・退出: 船（申請の後、次の管轄区域の通知が無統治区域なら進入、それ以外なら退出。申請は 1 回で使い切る）、徒歩（通知の後 10 秒 Location が変わらなければ）。追い読みでは今の時刻でも確定。
- 読み上げ: {船} は会社名を除く（ships のメーカーの名前と、同じメーカーの船名の頭の語）。「降りた」は「{船}から降りました。」。読み上げの結果を［ログ］に出す（最初の読み込みの分は 1 行にまとめる）。
- QT の開始の行は Game.log に無い（目的地の選択と最終の到着だけ）。

### そのほか
- 翻訳タブの読み取りボタンに版とチャンネル、新しい版なら黄色。LIVE・PTU は必ず並べ、Data.p4k の無いものは灰色。
- 日本語化でチャットのコマンドの名前（chat_command_* の英字 1 語の値と @ 版、25 個）は英語のまま書き出す。
