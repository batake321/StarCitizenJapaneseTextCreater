## 契約タブ（旧ミッションタブ）
- 画面の言葉をゲームの訳に合わせて「ミッション」→「契約」（ゲームが「PvPミッション」の所はそのまま）。
- カテゴリをゲームの MissionType の LocalisedTypeName（global.ini の語）に合わせた。Wiki だけの行と種類が空の行は「その他」。
- 列: カテゴリ・星系（raw_json の locality / location → 場所・名前）・評判（成功時。範囲が 2 種類以上なら範囲付き。勢力が null は「(勢力指定なし)」）。評判が上がる行は緑。選んだ契約のカテゴリを水色（項目の中の Border で塗る）。
- 同じ名前（日本語名・英語名・カテゴリ）の契約を 1 行にまとめ「×件数」。違う列は「 / 」でつなぐ。詳細の「■ 違い（n 件）」は詳細欄の上の契約（代表）と比べ、違う項目・違う行だけ。契約 ID は出さない。
- ランクはゲームの 7 段階。必要ランク（CG の minStanding、MBE の reputationRequirements の *_rankN。比較の向きは問わず、複数なら最小）→ 内部名の RankN → 難易度の推測（略号 VE/E/M/H/VH、Super→チーフ）。不明はどのランクで絞っても残る。
- 組合の欄に「勢力指定なし」。空欄の検索・クリアで一覧が空になる件、0 件の文言、操作が重なったときの上書き（_missionListRequest）を修正。勢力名は faction_reputation と翻訳から。
- ContractGenerator 行の評判（ContractResult_LegacyReputation）を読むようにした。

## ゲームログ・読み上げ
- VOICEVOX 速度（0.5〜2.0、ゲームログと Web チャットで共有）。VOICEVOX は 192.168.1.244:50021。
- 量子ジャンプ開始（行き先の選択。同じ行き先は 5 秒以内の選び直しをまとめる）／量子ジャンプ離脱（到着）。行き先を選ぶ行が出ない QT（契約の目的地へなど）は読めない。
- 操縦席を離れた（ClearDriver）と下船（チャンネル退出）を区別。保存済みの旧既定文は新しい既定文として扱う。
- 格納: ShipElevator の LoweringPlatform ＋ 35 秒以内の自分の OnRequestFetchVehicles ＋ ±3 秒に呼び出し無し。直後 60 秒の同じ船の下船は出さない。ID で決めた船が 60 秒以内にまた出たら取り消し。旧 StowRegex（切断・終了で出る）では作らない。読み上げは格納だけ 75 秒まで。
- 操縦: 乗船・同乗の船を「今乗っている船」として優先（退出で消す）。席を立った船の Failed 行は無視。FatalCollision の PlayerPilot: 1 で確定。
- ハンガーリクエスト完了の場面。到着の場所名は StarMapObject の name（starmap_names 表）で引く。_LEO を外して引き直しも。

## 詳細タブ・装備
- 詳細タブで船の既定装備を raw_json から表で（入れ子、×数、記号の打ち消し）。1 隻 40〜100 ms。
- ship_ports の抜けを修正（綴り違い・missile・付いている物の item_type で拾う。既存の行と付け替えのキーは不変、漏れなく含む船 65→1092）。反映には［装備データを再抽出］が要る。
- 交易ルートなど 3 つの表の 1 行おきの色の不具合を修正。

## 翻訳
- 地名・船名・武器・装備の名前のキーは AI に送らず原文、既存の AI 訳は起動時に「原文に戻す」扱いで英語へ（manual・official・csv・glossary は変えない）。設備（座席・扉など）・種類名そのもの・仮の文字・雛形・ビーコン・MISSION_* は名前に含めない。
- 文中の名前を {nameN} に置き換えて送り戻す（後に続く大文字の語もまとめる）。人名は AI に一覧を返させて確かめ、person_names に貯めて次から守る（同期・同梱 DB 入れ替え・バックアップ取り込みにも対応）。愛称も原文のまま。
- 訳の検査: {nameN}・~mission・\n の数・%・@・タグ・<0x..> の除去・空行・名前の前後の空白。
- E2B / E4B を翻訳に使う設定（既定は使わない。使う設定・E2B/E4B しか無いときは翻訳前にダイアログ）。appsettings の e2b/e4b を 192.168.1.244:11434 に直した。

## 残り（直し方が決まらず残したもの）
- ParseResponse: AI が訳の行を文字の \n で終えてから改行すると \n が二重になる（原文の段落と見分けられない）。\n の数の検査で弾かれ保存はされない。
- person_names の name 列が無い相手との同期は取り込み失敗、バックアップ取り込みは何もしない（glossary と同じ扱いの違い）。
