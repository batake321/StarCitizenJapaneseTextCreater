## v2.1.2 の自動更新（Revontulet さんの要望）
- 確かめるとき: 起動して 20 秒後と毎日の時刻（既定 08:00）。設定タブの「自動更新」で入切・時刻・［更新を確認］。GitHub の releases/latest（トークン無し、ETag、30 分以内は確かめない、403/429 は待つ）。
- 知らせ: ダウンロードの前に最前面・フォーカスを奪わない窓で聞く。更新内容（間の版も全部）を出す。ボタンは［終了して更新］［次回更新時に知らせる］（× も同じ）［今は更新しない］（この版を見送る）［後で手動で更新する］（自動更新を切る）。
- 差分: release.ps1 が `update-manifest.json`（ファイルごとの大きさ・SHA-256）と `<sha256>.gz` を載せる。前の版にあるファイルは前の版の URL を使い回す。同梱 DB は前の版からの zstd の差分（DbDelta.cs、zstd-prefix-v1、ZstdSharp.Port は元から入っていた）を版ごとに順に当て、合わなければ丸ごと。測った差分は gamedata_cache.db で 0.5〜5.3MB（丸ごと 144MB）。
- 入れ替え: インストール先のコード一式を `%LOCALAPPDATA%\StarCitizenJapaneseTextCreater\update\runner` に写し、同じ exe の `--apply-update` で、アプリの終了を待ってから入れ替える。控えを取り、失敗したら戻す。
- 立て直し: 途中の印 `update\journal.json`（1 ファイルごと、WriteThrough）、Mutex `Local\SCJPTextCreator_Updating`、本体の入れ替えの間だけ HKCU RunOnce `SCJPTextCreatorResumeUpdate`。印は片付いたときだけ消す。読めないときは手で直す方法を知らせる（journal.json.manual）。
- 作業フォルダがインストール先と同じときは DB を入れ替えない。manifest のパスは正規化してから確かめ、trade_cache.db などは受け付けない。
- **v2.1.2 は前の版に manifest が無いので全部（167MB）を載せた。実際の自動更新は、次の版を公開したときに初めて動く。** そのとき知らせの窓と入れ替えを画面で確かめてもらう。
