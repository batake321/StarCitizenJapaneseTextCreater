# チェックリスト: v2.5.x の地図（アプリとゲームで確かめる）

v2.5.0 のあとに入れた直しを、アプリとゲームで確かめるための一覧です。確かめた項目に印を付け、違っていた所は気づいたことを書いてください。

**前にすること**
- 新しいアプリで［マップをまとめて取り込む］をやり直す（地図のファイルの形を 15 に上げたため）。

## 階の分け方・名前
- [ ] Seraphim: フードコートが、ハンガー・クリニックの階と同じ層にある
- [ ] Seraphim: Galleria が 2 層で、2 層目（ADMIN）へは踊り場で右に折れる階段で上がる。踊り場は階段の一部として出る（階にならない）
- [ ] RR_CRU_L5・RR_HUR_L3: Galleria の 2 層が並ぶ（エレベーターが止まる層と、階段で下りた層）
- [ ] Checkmate: ハンガー → クリニックの階 → 大広間 → 店の階 の並び。大広間の中ほどの床の階段まわりは踊り場（階段）になり、ADMIN の部屋は階として残る
- [ ] Checkmate: 名前の替わり（Contested Access 02/04・Observation Deck・Entrance）が合っている
- [ ] 店の名前（Noodle Shop など）が階の名前にも括弧にも出ない
- [ ] 同じ名前の階が「▼ 名前（N 件）」にまとまり、中の行に高さ（例 -14.0 m）が付く
- [ ] 階段でつながる階に「（階段で: 相手）」が付く
- [ ] Lorville: Metro Center の階がある。Tammany and Sons がその階にある
- [ ] Area18 Medstation: −4 m の階と −2 m の階に分かれている
- [ ] New Babbage Aparelli: 現地で確かめる（今は「Aparelli」の名前のまま残している）
- [ ] Lorville Main Hall: 現地で確かめる（今は名前のまま残している）

## 地図の描き方
- [ ] 場所を選ぶと、斜めに重ねた階の図から始まる（Orbituary で赤い四角が出ない）
- [ ] 階段がアイコンではなく茶色の形で出る（下の階は実線、上の階は破線）。重なる階段は 1 つの形
- [ ] 階段でつながり高さが 1 m 以内の階は、同じ段に並ぶ（Checkmate の Material Processing・Galleria・Contested Access 02）
- [ ] 選んだ階の名札が画面の外にはみ出さない（Stanton Gateway の Bar）
- [ ] 長い行はマウスを乗せると全文が出る

## トラム・乗り場
- [ ] New Babbage・Lorville: シャトル乗り場（→ 次の駅）と地区が出る。Lorville の地区は 6 つ、New Babbage は 3 つ
- [ ] 全体図に道順を出したとき、乗る区間だけが明るい
- [ ] Area18: 電車の乗り場（Central・Bevic）が階に乗っている。エレベーターが拾えている
- [ ] Orbituary に「Contested Access 04」の地区が 2 つ出ない

## 一覧
- [ ] 取り込めない場所（QV Logistics Station（Nyx）が 305 行など）が一覧から消えている
- [ ] 同じ名前の場所が ▼ でまとまる（前哨基地（Monox）など）
- [ ] 床の無い場所に「（床なし）」が付き、選ぶと知らせが出る
- [ ] 洞窟・残骸・墜落現場は出ない
- [ ] ［マップをまとめて取り込む］で前哨基地なども取り込まれる

## 契約の地図
- [ ] Project Hyperion が「▼ Onyx Facility（120 か所）」の 1 つのリンク
- [ ] 床なしの場所へのリンクに「（床なし）」
- [ ] まだ取り込んでいない場所のリンクでも窓が開き、［読み込み］できる

## ［マップ］タブ（星系図とつながる）
- [ ] 地図のある場所に枠の印（実線＝取り込み済み、破線＝未取り込み）
- [ ] 印を押す・拡大し切ると場所の地図に切り替わる。縮小すると星系図に戻る（重ねて入れ替わる）
- [ ] ［場所の地図］／［星系図］ボタンと「場所」の検索
- [ ] ［情報］で［詳細］タブが開く
- [ ] ［詳細］の［地図表示］で［マップ］タブに移る
- [ ] ステーションの中にいるとき、［マップ］タブを開くと場所の地図から出る

## まとめて取り込むのボタン
- [ ] ［船舶・車両をまとめて取り込む］［マップをまとめて取り込む］が、全部取り込み済みなら押せない。マウスを乗せると数が出る
