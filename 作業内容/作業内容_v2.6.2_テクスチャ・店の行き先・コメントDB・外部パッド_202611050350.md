## ステーションの 3D（wwwroot/stationmap/view3d.js・view3d-worker.js・view3d.html、StationView3D.cs、StationView3DWindow.cs）

### テクスチャ（StationView3DTextures.cs 新規）
- 部品の材質 → PNG を Data.p4k から取り出して `Ship3DExports.Folder\stations3d_textures` に保存（長い辺 ≤ 設定 `Station3DTextureMaxPx`、既定 512。0 で貼らない）。
- UV は IVO の VERTSUVS と CrCh の P3S_C4B_T2S から。SourcePart に Uv/Tex。worker は COLK の三角形をテクスチャ id で並べ、`uvbuf`/`texbuf` を別 ArrayBuffer にして送る（1 つの ArrayBuffer が 2 GB を超えて失敗していた）。region.json に `textures:[{url,w,h,repeat,tint}]`。
- 画面: MeshLambertMaterial({map, color: tint}) を addGroup で。「テクスチャ」チェック。テクスチャ無しは灰色 0x888888。
- やっていない: 場所のパレット（primary/secondary tint）。置き方のパレットのデータが結び付かず保留（次回）。
- 区画のキャッシュの版 `region-cache-5`（StationView3DCache.cs）。

### 確認用の表示をやめた
- 判定の色分け（OCOL の複製）・輪郭線・白い柱・入口の緑赤の線・階段の的の玉・店の玉の色分けを描かない。判定の種類は `labs[k]`（Uint32Array）で持つだけ。Orison ±150 m の buf 1.92 GB → 1.25 GB。

### 札
- `distLabels`/`refreshDistLabels`（0.5 s ごとに距離を更新）。端末の札は `shopNameOf` で「店名（種類）」、`shortText`（16 字超で ": " があれば種類だけ）。端末の無い店にも店名の札（6 m / 3 m でまとめ）。
- 表示のチェック（view3d.html「表示: 店・端末・エレベーター・トラム・クエストの扉・パネル・コメント」）。印に `userData.cat`、`applyMarkVis()`、localStorage `view3d.marks`。

### 外部視点のパッドの引き出し線とキャプション
- 利用者: 「一度作ってんだから、今回入れてよ。外部になったときだけ出して」。v2.5.3 の旧方式（station3d/viewer.html・Station3DExports.cs）の見せ方（番号ごと・AI 専用は出さない・ハンガーは大きさでまとめ・色分け・小さな丸・太い引き出し線）を新方式へ移植。外部視点（歩くモードでなく、カメラが地点の半径の外）のときだけ出す。
- 担当の報告は下の「担当の結果」に追記。

### 店を行き先に選んだとき（placeStart）
- 順: ① 端末の前（30 m 以内）→ ② カウンターの前 → ③ 店の点。入口・8 方向の段は店では使わない。
- カウンターは店の印と同じ階（z −2.5 m〜+0.5 m）の箱だけ（3D の距離 10 m で集めていて真上の店のカウンターが入り、Kel-To が 2 階に出ていた）。
- 見通しの的を箱の中心から近い面の縁に（中心だと必ず自分に当たって客側が落ち、厨房の奥が残っていた）。辺の選び方: 外側にほかのカウンターが少ない → 歩ける距離が長い → 店の印から遠い。

### 販売品（GameDataExtractor.DeliverableSources.cs）
- MatchShop の決まり 5: 価格の売り場の名前にエンティティ名の語が含まれる（同点は語が全部相手に含まれる方で少ない語数）。`LinksRuleVersion` "4"。Orison Kel-To 4 品 → 67 品。
- 残り（結び付かない）: Refinery Shop・Pyro Cargo Shop・Casaba Outlet(-001)・Levski の重複。データが曖昧で保留。
- 枠はホイールでスクロール、見出しと ✕ は sticky。`SALES_R = 3`。

### 歩くモードのコメント（StationNotes.cs 新規）
- `view3d_notes.db`、表 `notes(id, record, x, y, z, text, created_utc)`。メッセージ `notesGet`/`noteAdd`/`noteDelete`（StationView3DWindow.cs）。
- Enter はいつでも（録画中でなくても）。決めた瞬間に印。印（Sprite）を押すと confirm で消す。再生は従来どおり rec.comments から。
- 未確認: WebView2 で window.confirm が出ること、仮想ホストで localStorage が効くこと。

### 歩くモードの手すり
- `STEP_FLOOR_MIN = 0.35`、`tallObjectAt`: 段差 0.35 m 超のとき、面の真下の面との差が STEP（0.6 m）を超えれば「手すりの高さ」で上がらない。`blocked()` に行き先の縦の線分。種類名（床・坂・階段）の決め打ちはしない（利用者「こういうハードコードはダメ」）。

### エレベーター・トラム
- 降りる側を扉の向き（局所 +Y）で決める（BuildGeo/worker）。/elev/ の経路の扉も扉と見る（truck_shaft_door_double_a）。
- `STOP_DZ = 3`、`TRAM_NEAR = 10`。stopDist は xy。

### 床の穴（StationFill.cs）
- KeepWide: 幅 0.5〜10 m。平らな穴（z の広がり ≤ 0.5 m）は上限なし（Orison の 10.48 m の床）。view3d_layout.db 版 5（1,148 種、72.6 MB）。

### 読み直し
- nearCheck: 歩くモード以外でカメラが半径の外なら読み直さない。失敗後 30 s は読み直さない（`lastFail`/`FAIL_HOLD_MS`）。失敗時は「読み込めませんでした」。
- `logApp()` → {type:'log'} → App.AppendStartupLog。
- 取り出し中・作画中は右下の小さな形（#prog）に統一。

## 武器・装備の 3D
- ［詳細］の名前の右（h2 の中、inline-block）に `?thumb=1` の 192 px の斜めの絵、押すと 3D。`?item=1` で船外／船内と side を出さない。赤い ✕（Ship3DWeb.CloseRequested → DetailPanel.HideShip3D / Ship3DWindow.Close）。
- emissive に emissiveMap が無ければ 0（クーラーが真っ白）。白のテクスチャ無しは灰色。
