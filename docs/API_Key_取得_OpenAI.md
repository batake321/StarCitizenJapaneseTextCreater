# OpenAI (ChatGPT) API キー取得手順

Star Citizen 日本語訳ソフトで OpenAI (GPT-4.1 等) を翻訳エンジン・チャットバックエンドとして利用するための API キー取得手順です。

---

## 1. 前提条件

- メールアドレス（Google / Microsoft / Apple ログインも可）
- クレジットカードまたはデビットカード（API 利用には課金設定が必須）
- ブラウザ

**注意**: ChatGPT Plus（月額 $20 のチャット版サブスク）と API 利用の課金は**別物**です。API を使うには OpenAI Platform での課金設定が別途必要です。

---

## 2. アカウント作成

ブラウザで以下にアクセスします。

https://platform.openai.com/

**「Sign up」** からアカウントを作成します。既に ChatGPT アカウントがあれば、そのままログインできます。

---

## 3. 課金設定（Billing）

1. ログイン後、左メニューの **「Settings」→「Billing」** へ
2. **「Add payment method」** からクレジットカードを登録
3. **「Add to credit balance」** で初期チャージ（最低 $5〜）

従量課金式（プリペイド）です。クレジットを使い切るとリクエストが拒否されます。

**自動チャージ**: 「Auto recharge」を ON にすると、残高が少なくなった時に自動で追加チャージされます。意図しない課金を防ぐには OFF のままにしておくことを推奨します。

---

## 4. API キーの発行

1. 左メニューの **「API Keys」** をクリック
2. **「Create new secret key」** を押下
3. キーに名前を付ける（例: `starcitizen-translator`）
4. 表示された `sk-proj-...` で始まる文字列をコピー

**キーはこの画面でしか全文表示されません。** 閉じてしまうと再表示不可なので、必ず安全な場所に保存してください。紛失時は削除して再発行します。

---

## 5. モデルの選定（翻訳用途）

| モデル | 特徴 | 翻訳用途の目安 |
|---|---|---|
| `gpt-4.1` | 最新・高品質 | ロア・長文・専門用語が多いテキスト |
| `gpt-4.1-mini` | バランス型・低コスト | ミッションテキスト・メニュー全般（推奨） |
| `gpt-4.1-nano` | 最安・高速 | UI ラベル・短文・大量処理 |
| `gpt-4o` | マルチモーダル対応 | 高品質な翻訳が必要な場合 |
| `gpt-4o-mini` | 4o の軽量版 | コスト重視の翻訳 |
| `o3-mini` | 推論特化 | 複雑な文脈理解が必要な場合 |

Star Citizen 用途であれば **`gpt-4.1-mini`** がコストと品質のバランスが良くおすすめです。

### 料金目安（1M トークンあたり）

| モデル | 入力 | 出力 |
|---|---|---|
| `gpt-4.1` | $2.00 | $8.00 |
| `gpt-4.1-mini` | $0.40 | $1.60 |
| `gpt-4.1-nano` | $0.10 | $0.40 |

> Star Citizen の全テキスト（約 10 万行）を翻訳する場合、gpt-4.1-mini で $2〜5 程度が目安です。

---

## 6. アプリでの設定方法

### 手順

1. アプリを起動し、右上の **「AI 設定」** ボタンをクリック
2. **「バックエンド追加」** をクリック
3. 以下の通り設定:

| 項目 | 設定値 | 説明 |
|---|---|---|
| **Type** | `OpenAI` | ドロップダウンから選択 |
| **API Key** | `sk-proj-...` | 手順 4 で取得したキー |
| **Model** | `gpt-4.1-mini` | ドロップダウンから選択（手入力も可） |
| **Batch** | `40` | 一度に送る翻訳数（調整可能） |

4. **「有効」** チェックボックスを ON にする
5. **「保存」** をクリック

### 設定例

```
┌─ OpenAI ───────────────────────────────────────────┐
│ Type: OpenAI    Model: gpt-4.1-mini                │
│ API Key: [sk-proj-***]                             │
│ Batch Size: 40       [x] 有効                      │
└────────────────────────────────────────────────────┘
```

### 複数バックエンドとの併用

OpenAI は Claude・Gemini・Ollama と同時に有効化できます。複数バックエンドを有効にすると、バッチを分散して**並列翻訳**します。

例: Claude (高品質) + OpenAI gpt-4.1-mini (高速) を併用すれば、品質を保ちながら処理速度を向上できます。

---

## 7. チャット機能での利用

チャットタブでも OpenAI を使えます。チャットバックエンドとして設定すれば、AI Tool Use (Skills) に対応し、船・武器・ミッション等のゲームデータを自動検索して回答します。

チャットで使用するバックエンドは、チャットタブ右上のドロップダウンから選択します。

---

## 8. レート制限と Usage Tier

OpenAI API は使用実績に応じて Tier が自動昇格し、レート上限（RPM / TPM）が拡張されます。

| Tier | 条件 | RPM 上限 |
|---|---|---|
| **Free** | 初期状態 | 制限あり |
| **Tier 1** | $5 課金 | 500 RPM |
| **Tier 2** | $50 以上の支払い + 7 日以上 | 5,000 RPM |
| **Tier 3** | $100 以上の支払い + 7 日以上 | 5,000 RPM |

大量翻訳バッチを走らせる場合は、Platform の **「Usage」** から現在の使用量と上限を確認してください。

---

## 9. トラブルシューティング

| 症状 | 原因 / 対処 |
|---|---|
| `401 Unauthorized` | キー誤り / 失効 → API Keys から再発行 |
| `429 Rate limit exceeded` | RPM/TPM 超過 → しばらく待ってリトライ |
| `429 insufficient_quota` | クレジット不足 → Billing から追加チャージ |
| `400 Bad Request` | モデル名・パラメータを確認 |
| `503 Service Unavailable` | 一時的過負荷 → 数秒後リトライ |

---

## 10. セキュリティ上の注意

- API キーをソースコードや公開リポジトリに載せない
- 漏洩時は Platform の **API Keys** から即時削除 → 新規発行
- 用途別にキーを分け（dev / prod）、不要になったキーは削除
- **Usage Limits** で月額上限を設定しておくと、意図しない高額課金を防げます
